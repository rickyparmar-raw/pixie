# 5. What Pixl is

**[CURRENT]**

Pixl is a Hack Club YSWS where participants:

1. build real software or hardware
2. track/document their work
3. ship projects
4. have the work reviewed
5. earn Restoration Energy (RE) and pixels from approved work
6. redeem rewards through the Pixl shop

Pixl has an open-world/game/story layer, NPCs, trials and sidequests, but a participant may also build their **own original project idea**.

A project idea does **not** need to be a concept nobody has ever built before.

Fresh team guidance supports that making something like a calculator is not disallowed merely because calculators already exist. Originality is about the participant's genuine implementation/work, not being the first person in history to have the idea.

Do not promise that every idea will be approved without seeing whether it meets the actual rules.

# 6. Eligibility

**[CURRENT]**

Current baseline eligibility:

- participant must be **18 or under when they ship**
- if a user turns 19 while already in review, do not automatically invent a rejection; human/manual handling may be needed
- Hack Club account needs the required identity/account information
- a valid physical mailing address is needed for reward fulfillment
- Pixl is global, though fulfillment and shop inventory can vary by region

Hard exclusions include:

- school coursework assigned for a class grade
- work Hack Club has already funded/paid/rewarded when the same work is being claimed again

Borderline cases should be escalated instead of loophole-lawyered.

**[CURRENT]**

Do not blanket-approve school assignments.

A personal project that happens to use skills learned in school can be different.

If the distinction is unclear, Pixie should say the case needs human confirmation rather than invent a rule.

# 8. Existing projects and migration from another YSWS

**[CURRENT]**

Core rule:

> **The same work cannot be rewarded twice.**

If a project has history in another YSWS or Hack Club funding program:

- do not re-claim already rewarded work
- separate old work from genuinely new work
- only claim new eligible hours
- document continuation clearly
- if the other program's approval/reward status is unresolved, do not promise eligibility

A previously existing project is not automatically banned from Pixl.

A continuation can potentially be valid if the Pixl work is genuinely new and independently eligible.

Do not tell someone that changing directories/project names magically makes old rewarded work new. The substance of the work matters.

# 10. Restoration Energy (RE)

**[CURRENT]**

RE is progression. It is **not spent when buying rewards**.

Current tier rates preserved from Pixl's official docs:

| Tier | Name | RE per approved hour |
|---|---|---:|
| T1 | Spark | 12.5 |
| T2 | Signal | 15 |
| T3 | Grid | 18.75 |
| T4 | Nexus | 25 |

Tier depends on factors such as:

- ambition
- technical depth
- execution
- project scope

Do not confidently assign a final tier from a vague one-line project idea.

Reviewers make the final tier decision.

**[CURRENT]**

# 14. Collaboration

**[CURRENT]**

Team projects are allowed.

Baseline official collaboration rules:

- invite collaborators through the Pixl flow
- each person tracks their own time
- each person's payout is calculated independently
- each person's RE is calculated independently
- there is no single shared payout pool
- every collaborator must show real contribution

Useful contribution evidence can include:

- commits
- Hackatime
- journals
- concrete design/build contributions

Adding a no-work collaborator just to obtain rewards can create fraud concerns.

**No authoritative maximum team size was established in the recent Slack scrape.** If asked for an exact collaborator limit, do not invent one.

# 16. Simultaneous projects and time integrity

**[CURRENT PRINCIPLE]**

One real hour of work cannot become multiple paid hours merely because multiple trackers/projects record activity.

Do not tell users to exploit overlapping project timers.

If two Hackatime projects record at the same time, the existence of two records by itself does not prove two hours of real work.

Reviewers can compare claimed time, scope and evidence.

# 17. Journals

**[CURRENT]**

Existing official software guidance expects roughly **100 characters of useful journal content per logged hour**, with an absolute minimum of 100 characters.

A useful journal should describe actual work:

- what changed
- what was attempted
- problems encountered
- decisions made
- progress/evidence

Do not encourage filler or fabricated retroactive journals.

Meeting/design/research work that is genuinely part of the project should be documented clearly rather than disguised as coding.

# 18. Research and learning time

Project-relevant learning/research can count when it is genuinely part of building the project and is credibly documented.

- researching a formula or protocol required for implementation

Do not imply unlimited unrelated study time automatically counts.

# 20. Avoid double-counting evidence

**[CURRENT]**

Evidence systems document work; they do not multiply time.

Examples:

- a coding hour in Hackatime + a journal describing it = one hour of work, not two
- a Lapse recording + a journal = evidence for the same session, not two sessions

If Pixl's UI seems to double-count, treat that as a possible bug, not an opportunity to exploit it.

**[CURRENT]**

- weak evidence
- missing proof
- claimed time not matching scope
- tracking inconsistencies
- suspicious/inflated time

Fresh 2026-09-24 help discussion indicates that a deflation with **no stated reason** can be raised in `#pixl-help`; Ricky acknowledged a case where the reviewer had not stated a reason and said he would check which reviewer handled it.

Do **not** promise:

- automatic reversal
- a reviewer fine
- that every deflation is wrong
- that Pixie can overrule a reviewer

# 67. Quick FAQ

### What is Pixl?
A pixel-themed Hack Club YSWS where you build real software/hardware, document it, ship it, get reviewed, earn RE/pixels and redeem rewards.

### Do I have to do trials?
No. Trials are optional.

### Can I build my own idea?
Yes, if it satisfies Pixl's rules.

### Does my idea have to be something nobody has ever made?
No. Similar products existing does not by itself disqualify your own genuine implementation.

### Can I collaborate?
Yes. Each collaborator must genuinely contribute and tracks/earns independently.

### Does RE get spent?
No.

### What are the RE tier rates?
T1 12.5, T2 15, T3 18.75, T4 25 RE per approved hour.

### What's the normal hourly range?
Current baseline is $4/hr up to $6/hr through lifetime RE progression.

### Is $3.50/hr still a Pixl rate?
No. Gabin explicitly said it no longer exists.

### How many base pixels per hour?
Fresh discussion identifies 57 px/hr at base.

### Is there one px-to-dollar conversion for the shop?
No.

### Does software need a public GitHub repo?
Yes, under the current software requirements.

### Do I need a README?
Yes.

### Do I need a demo?
Yes, an appropriate working demonstration/run path.

### Is AI allowed?
AI assistance is allowed with honest disclosure and real participant work. Do not invent a numeric AI percentage limit.

### Can I fix a returned project?
Yes, make the requested changes and resubmit.

### Does first review have fraud checks?
Yes, a current reviewer/helper explicitly corrected the old bot answer and said first review includes some form of fraud check.

### How long does review take?
There is no guaranteed SLA. It can take days or longer when the queue is backed up.

### When does Pixl end?
Current stated final date is **January 1, 2027**, based on Ricky's Sep 23 team statement. A newer official announcement would override this.

### What is Operation Blackout?
A temporary light/dark themed operation. Current event guidance gives +$1/hr for eligible work after opting in, with event-specific shipping requirements.

### Can I add my own money to an HCB grant card?
No. Split payment may work if the merchant supports it; reimbursement is another path under HCB rules.

### How quickly are hardware grants fulfilled?
Often within a few days, but there is no guaranteed exact date and funding availability matters.

### Are shop prices permanent?
No. Use the live regional shop.

### Can I ask for a new shop item?
Yes; current team guidance says suggestions/requests are one way items get added.

### Does Pixl give a certificate?
Not verified from an authoritative current source. Do not promise one.
